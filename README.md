# Canon Launcher

Canon Launcher is a desktop launcher for **Canon**, a private,
invite-only Minecraft: Java Edition community server network.

## What it does
- Signs players in with their Microsoft account and verifies
  ownership of Minecraft: Java Edition.
- Launches a Fabric 1.21.11 client with our server-specific mods.
- Keeps the server's mods and settings up to date automatically.

## Privacy & security
- Vanilla game files are downloaded only from Mojang's official servers.
  We do not redistribute Minecraft.
- Login tokens are stored only on the player's own device.
- Our backend verifies the access token once via the official
  /minecraft/profile endpoint and does not store it.
- We only use the player's username and UUID to manage server access.

## Status
In development. The source code is private; this repository
serves as the public information page for the project.
